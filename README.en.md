# GROMACS-GUI

[中文](./README.md) | [English](./README.en.md)

GROMACS-GUI is a desktop application built with Python and PyQt6 for organizing common GROMACS molecular dynamics workflows into a clearer graphical interface.

The project currently focuses on two workflow groups: standard solution-system simulation and protein-ligand complex preparation followed by simulation.

## Overview

### Solution Simulator

For standard solution systems, the current workflow includes:

- topology generation and box setup
- energy minimization
- NVT / NPT equilibration
- production MD
- trajectory processing and basic analysis

MDP parameters can be edited for minimization, equilibration, and production stages. The analysis module currently supports plotting and calculation for `RMSD`, `RMSF`, and `gyrate`.

### Ligand Simulator

For protein-ligand complex systems, the current workflow includes:

- importing ligand topology and structure files generated by external tools such as `CGenFF`, `ATB`, and `ACPYPE`
- receptor preprocessing with `pdb2gmx`
- merging protein and ligand coordinates
- automatic `topol.top` update
- solvation and ion addition
- integration with downstream EM, EQ, MD, and analysis steps

## Setup

### Requirements

1. Python 3.8 or later
2. A working GROMACS installation

### Install

```bash
git clone https://github.com/JohnLei00001/GROMACS-GUI.git
cd GROMACS-GUI
pip install -r requirements.txt
```

## Configuration

Before running the application, set the local `gmx.exe` path in [`src/core/config.py`](./src/core/config.py):

```python
GMX_PATH = r"C:\path\to\your\gmx.exe"
```

## Run

On Windows:

```bash
run.bat
```

Or run directly with Python:

```bash
python src/main.py
```
